# laboratorio.utilidades

Colección de ejemplo del laboratorio (playbook 32): un módulo (`lab_eco`) y
un filtro (`etiqueta_lab`) empaquetados con `galaxy.yml`.

No está pensada para Galaxy de verdad — existe para aprender el ciclo
`ansible-galaxy collection build` → `install -p` → consumo por FQCN, y las
trampas de resolución que el playbook 32 demuestra.
